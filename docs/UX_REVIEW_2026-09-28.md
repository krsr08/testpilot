# Enterprise UI review — 28 September 2026

The running product was reviewed at laptop viewport size across Workspace, Projects, Operations, and Billing, then reconciled with every implemented route and API capability.

## Findings corrected

1. Workspace KPIs collapsed into a text stream. They now use a responsive card grid.
2. Navigation mixed daily work and administration. It now groups Workspace, Manage, and Administration tasks.
3. The sidebar exceeded common screen height. It now scrolls independently with tighter spacing.
4. Processing data was buried in project settings. The new Operations Center shows dependency health, worker lag, workload, progress, attempts, and failures across accessible projects.
5. Billing was buried in Settings. The new Billing & Usage screen presents plan, consumption, limits, upgrade state, and governance.
6. Project navigation could overflow. Tabs now scroll horizontally instead of clipping.
7. Cards now use consistent borders, spacing, radius, and subtle elevation.
8. Operational state now uses a clear healthy/degraded indicator with dependency cards.

## Screens added

- `/operations` — workspace reliability and background processing
- `/billing` — workspace plan and document usage

## Existing functional screens retained

Projects, Workspace, Authoring, Requirements, User Stories, Test Cases, Executions, Traceability, Traceability Graph, Intelligence, Review Queue, Search, Notifications, Team, Integrations, Audit, Profile, Settings, and Project Settings.

## Recommended future screens

These should be added when their underlying capabilities are implemented:

- Data retention, legal hold, and privacy requests
- Prompt releases and evaluation history
- CI/CD connections and automated run results
- Connector field mapping and synchronization conflicts
- Organization-wide access review campaigns
- Model usage and cost allocation

The future screens are product dependencies, not cosmetic placeholders.
